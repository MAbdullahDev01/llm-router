# LLM Router (SHIP-style)

## What is LLM Routing?

- The process of automatically directing the user's prompt or task to the most suitable llm available.
- This is based on the following factors:
  1. cost
  2. response speed
  3. task complexity
  4. required output quality

## Why is it important?

- Helps save companies money by efficiently prompting llms

## How to measure if the LLM Router works?

- The following metrics should be considered:
  1. Answer quality
  2. Routing accuracy
  3. Cost per request
  4. Latency
  5. Failure rate

## Different methods to route prompts:

1. Rule-based
2. Classification-based
3. Learned routing
